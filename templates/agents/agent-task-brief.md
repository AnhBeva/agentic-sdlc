# Agent Task Brief Template

## Mục tiêu

Giao task cho agent với scope, contract và gate rõ ràng.

## Operating principle

Human owns intent, architecture, design standard, contracts; agents own execution inside constraints.

- Human supervisor:
- Agent/tool:
- Reviewer:

- Feature spec:

- Module contract:
- Ownership map:
- Test/eval expectation:

## Output bắt buộc

- Files/modules allowed:
- Files/modules forbidden:
- Implementation steps:
- Tests/evals to run:
- Evidence to report:
- Escalation conditions:

## Checklist pass/fail

- Pass khi agent có thể thực thi mà không tự quyết kiến trúc, UI standard hoặc contract.
- Fail khi task quá rộng, scope chồng lấn, test không rõ hoặc owner không rõ.
