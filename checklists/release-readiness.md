# Release Readiness Checklist

- [ ] Acceptance criteria đạt.
- [ ] Unit/integration/contract/E2E tests đạt theo phạm vi.
- [ ] Eval plan đạt nếu có agent output hoặc workflow chủ quan.
- [ ] UI/UX review đạt nếu có UI.
- [ ] Security/threat model đạt nếu có quyền, dữ liệu nhạy cảm hoặc tool mới.
- [ ] Merge gate report có đủ evidence.
- [ ] Rollback hoặc canary plan rõ.
- [ ] Monitoring/alert sẵn sàng.
- [ ] Required reviewers đã approval.
