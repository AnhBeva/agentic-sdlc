# UI/UX Checklist

- [ ] UI dùng design tokens, không hard-code màu/spacing/typography.
- [ ] Component nằm trong component library hoặc có component contract được duyệt.
- [ ] Đủ default, loading, empty, error, disabled, focus states.
- [ ] Responsive đạt ở mobile/tablet/desktop.
- [ ] Text không tràn, không đè, không làm vỡ layout.
- [ ] Accessibility đạt contrast, keyboard navigation, visible focus.
- [ ] Screenshot diff được review nếu có thay đổi thị giác.
- [ ] Designer/product duyệt pattern mới.
