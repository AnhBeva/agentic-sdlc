# Observability Checklist

- [ ] Mỗi agent run có trace.
- [ ] Tool calls được ghi lại.
- [ ] Token/cost được theo dõi.
- [ ] Loop/step count có guard.
- [ ] Quality, cost và reliability có dashboard.
- [ ] Alert có owner và escalation path.
- [ ] Production trace sampling được định nghĩa.
- [ ] Failure analysis tạo test/eval/guardrail mới.
