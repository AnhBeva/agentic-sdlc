# Large Module Checklist

- [ ] Module được chia theo bounded context/domain capability.
- [ ] In scope/out of scope rõ.
- [ ] Public API/event/schema rõ.
- [ ] Data owner và write/read access rõ.
- [ ] Error model, retry và idempotency rõ.
- [ ] Contract tests có cho biên module.
- [ ] Integration/E2E flow đại diện nghiệp vụ thật.
- [ ] `AGENTS.md` module có boundary, dependency rules và test command.
- [ ] Bug production tạo regression test/eval mới.
