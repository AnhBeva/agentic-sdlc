# Architecture Checklist

- [ ] Feature spec đã duyệt.
- [ ] ADR có context, decision, alternatives, consequences, rollback path.
- [ ] Module boundary rõ.
- [ ] Data ownership rõ.
- [ ] API/schema/event contract rõ nếu liên quan.
- [ ] Dependency direction được kiểm soát.
- [ ] Threat model có mitigation cho rủi ro cao.
- [ ] Test strategy gắn với quyết định kiến trúc.
- [ ] Không giao agent implement khi còn quyết định kiến trúc mơ hồ.
